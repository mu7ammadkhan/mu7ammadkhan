### Darzi Plus

**Tailor Shop Management · Commercial Product**

**Key workflows:** customers, unlimited measurements, individual and family orders, delivery dates, advance and remaining payments, tailor/karigar assignments, expenses, reports, receipts, work slips, Urdu/Sindhi printing, backup, licensing, installer/updater and WhatsApp-ready reminders.

**Suitable for:** men's and women's tailors, boutiques, fashion studios, uniform businesses, bridal designers, alteration shops, multi-worker tailoring businesses and home-based stitching businesses.

### Nova Control

**Full-Stack IoT Automation · Commercial Product**

A responsive automation platform that connects modern web software with ESP32-powered devices. Users can organize rooms and devices, control appliances and monitor realtime state through a web dashboard.

The first version used React and Firebase. The product direction is evolving toward Next.js, TypeScript, MongoDB and MQTT for scalable realtime control.

**Key workflows:** authentication, rooms and devices, realtime state, appliance control, ESP32 integration, MQTT communication, responsive dashboards and voice commands.

**Suitable for:** homes, apartments, offices, shops, showrooms, warehouses, schools, labs, guest houses and custom automation environments.

**Recognition:** Awarded at the FYP Exhibition.

[View the Nova Control case study](https://muhammadkhandev.vercel.app/projects/nova-control)
